# Bitácora de uso de IA — Registro inicial

Herramienta utilizada: ChatGPT.

1. Se definió el problema y el alcance de un sistema de movimientos de almacén mediante conversación iterativa.
2. El estudiante seleccionó y aprobó reglas funcionales: stock inicial cero, movimientos independientes, validación de salidas y corrección antes de confirmar.
3. ChatGPT ayudó a redactar el diseño de sesiones 1 a 4.
4. Se solicitó generar una primera versión de código Python/Flask, pruebas Pytest y archivos de despliegue.
